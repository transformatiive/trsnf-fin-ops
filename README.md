# Transformatiive Financial Dashboard

Self-refreshing financial operations dashboard for Transformatiive Lda. Pulls
data directly from Zoho Books, Moloni, and the Zoho Partner Store on load; AI
performance analysis generated by Claude Sonnet.

## Stack

- Node.js + Express backend (`server/`)
- React + Vite frontend (`client/`)
- Deployed on Replit

## Running locally

```bash
npm install
cp .env.example .env   # fill in secrets
npm run dev            # runs server (3000) + vite (5173) concurrently
```

Open <http://localhost:5173>.

## Running on Replit (production)

1. Import repo into Replit (Node.js template).
2. **No secrets required** — credentials are pulled at startup from the
   Transformatiive credential vault (see below).
3. `.replit` already sets `run = "npm run dev"` for dev and runs
   `npm run build && npm start` for deployment.
4. Enable **Always-on** in Replit settings.

### Credentials: pulled from the vault, not Replit Secrets

On server start, `server/services/vault.js` GETs:

```
https://trnsf.up.railway.app/webhook/credential-vault?action=get&epic_key=TRNSF-INTERNAL
```

and populates `process.env`. The vault provides Zoho Books + Moloni credentials
automatically. You can still set any value as a Replit Secret to override the
vault — env vars take precedence on first load.

**Must be set as Replit Secrets** (not currently stored in the vault):

```
ANTHROPIC_API_KEY        # required for AI analysis panel
PARTNER_EU_EMAIL         # optional — Partner Store EU subscriptions
PARTNER_EU_PASSWORD
PARTNER_COM_EMAIL        # optional — Partner Store COM subscriptions
PARTNER_COM_PASSWORD
```

Force a reload after rotating a vault secret:

```
POST /api/vault/reload     (auth required)
```

### Optional overrides

```
CREDENTIAL_VAULT_URL    # override vault base URL
CREDENTIAL_VAULT_EPIC   # override epic key (default TRNSF-INTERNAL)
APP_PASSWORD            # override the login password baked in
PORT                    # defaults to 3000
```

## Authentication

A single password gate protects all `/api/*` routes (except `/api/login`,
`/api/session`). Password: `!TransformatiiveAdmin2026#` (override by setting
`APP_PASSWORD` in Replit Secrets).

Sessions last 12h and are signed HMAC tokens kept in `sessionStorage`.

## API

- `POST /api/login` `{ password }` → `{ token }`
- `GET  /api/session` → `{ valid }`
- `GET  /api/dashboard[?refresh=1]` → full financial payload (5-min cache)
- `GET  /api/analysis?tab=actions|pl` → SSE stream of Claude Sonnet analysis
- `GET  /api/health` → credential health check

## Key design notes

- **COGS framing.** Zoho licence costs are 100% pass-through with a guaranteed
  18% margin. COGS in the P&L represents timing risk (paying Zoho before
  receiving from client), NOT a margin problem. Novembro is the big one:
  Leasys PT ~€57k outflow before ~€67k inflow.
- **Moloni grant endpoint uses GET**, not POST — critical gotcha.
- **Zoho Books tokens cached in memory** and refreshed automatically on 401.
- **Backend caches `/api/dashboard` for 5 minutes**; pass `?refresh=1` to bust.
